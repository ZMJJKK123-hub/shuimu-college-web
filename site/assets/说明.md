## 命名规则

```
分类描述-主题-补充_宽x高.扩展名
```

例：
- `logo-页头-白色横版-清华大学水木书院_240x47.png`
- `轮播01-从水木向未来_1880x970.jpg`
- `人物肖像-男-西装02.jpg`（序号 02 用于区分同类的多张）
- `合影-海外实践-Instagram总部.jpg`

每张图的**原始路径**都写在 `素材总览.html` 的卡片上（如 `__local/D/43/91/3A7F2BB6….jpg`），并标明它出现在哪些页面，可完整回溯到镜像文件。

## 两点必须说明

1. **`16-样式表` 里的 CSS 不能单独渲染页面。** 实测：CSS 中有 **2089 处 `rem` 单位**依赖原 `js/set.js` 动态设置根字号，另有 **6 处 `url(#clipPath1/2/3)`** 直接引用首页内联 SVG，还有 **257 处 `.swiper-*` / 35 处 `.on` / 37 处 `.active`** 依赖 JS 运行时生成。只读 CSS 可以准确拿到配色、间距、字号、动效参数（这些足够在新项目里复刻设计语言），但要**看到**版式必须有 HTML 骨架 + JS。
2. **`17-结构参考` 里的 HTML 不会渲染成原样式**（它的 CSS/JS/图片路径指向原目录结构）。需要真正跑起来的话，说一声，我把 `js/` + `system/` + 首页所需的 25 张图补齐并修好路径，约 17 MB 可得到能真实打开的首页。
